# UL 随行 0.4.1-dev · 客户整单每日任务

本版把销售与包装任务页按客户订单号第一个 `#` 前的完整文本合并为客户整单卡。每页显示 20 张卡，展开后仍可操作原系统订单行。销售按整单记录跟进；采购仍按商品合并事项，并显示受影响客户整单数与只差此商品的整单数；两个包装岗位的负责人、每人最多 3 行的限制、打印锁和 ERP 发货确认口径保持原规则。

## 安装

安装 `UL-Workbench-0.4.1-dev.apk` 覆盖原开发版。应用 ID 仍为 `com.ul.workbench.dev`，版本号 14，使用原开发签名；覆盖安装保留会话、设备 ID、草稿和本地待提交记录。N150 后端镜像为 `ul-workbench:0.5.2`，数据库自动从 v6 增量迁移到 v7；升级前已经制作一致性加密 NAS 备份。

管理员进入“任务”页后，先用“全部人员”查看待补齐、待包装、待发货和待核对。相同前缀客户名称为空或冲突时，卡片保持“待核对”，不得直接认定整单齐货。详情中的“调整负责人”用来处理旧销售事项归属不一致的订单；处理记录和人员管理保持原入口。开启自动派工后，预览期已经出现而尚未安排的整单会补充销售负责人。新订单行加入原客户订单时，原卡显示“订单行已变化”，跟进历史保留。

整单只在全部有效未发行实物齐货、每行明确确认已包装且没有核对问题时显示“可安排整单发货”。只打印标签不会计入包装完成。已出库未结存行不进入待包装缺口。业务数据仍由手动“更新订单”同步，不自动读写 ERP；本版上线不触发物流字段写回。
