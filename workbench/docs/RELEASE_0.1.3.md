## 本次修改

1. 库存手动输入第一栏为商品编号。两位字母 + 四位数字，小写转大写，合法六码立即精确查询；输入前缀后请求数字键盘。名称、规格、型号和更多条件保留，编号查询清空残留组合条件。
2. 库存多结果默认不选；只有总条数与返回项都为 1 时自动选中。翻页保留人工选择；订单仍默认选当前页。
3. 标签保留纸张、字段区域与二维码信息，调整字重、字号、基线和长内容适配，保持标准号与规格之间的空格。排版示意不能替代打印机实际出纸。
4. 设备页的待核对清单增加“已核对，确认入账”。核对单据及明细后，保存人工核对记录并收起该条；不重传 ERP。网络中断后只重复确认同一批，不再上传。
5. 修复 PALL01 识别完第六位后，按键释放及扫码回车穿透到“停止发送”的路径。打印忙碌时消费后续扫码输入；保留手动停止、未知打印结果保护和原 BLE 传输参数。

## 原因与数据保护

真实打印台账存在 prepared 及 cancelled/0 字节任务，吻合打印前误触取消，未用清空取消标志或加快 BLE 发送去掩盖问题。未知库存批次保留原条目，升级时不自动认定成功；用户可通过新入口核对。人工确认在独立表保存设备、时间和原状态；原导入文件、回执及提交标记仍保留。

本轮仅修改独立 App 和 5191，5088 与三份源文件保持原路径与原逻辑。没有实发测试标签、没有创建或再次上传真实报损报溢单据。
