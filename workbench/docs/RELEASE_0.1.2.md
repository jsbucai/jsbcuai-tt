# UL 随行 0.1.2-dev

2026-09-10，原生 Android，红 / 白 / 黑风格，订单 / 库存 / 设备三个入口保持。

## 操作

- 订单查到商品后，扫码 `PALL01` 打印当前选中项；扫码 `PBOX01` 打开当前选中项的拆箱数量输入，确认后打印。
- 库存页两个码均直接打印当前选中项；普通商品扫码仍用于查询。沿用现有忙碌、未连接、编辑中和打印结果不明保护。
- 库存点击商品，选择报损或报溢、填写正数量和可选备注，加入清单。同类型相同商品自动累加。
- 到设备页检查草稿，可移除尚未上传的项；按类型确认后统一上传，一张单包含该类型的所有明细。
- 提交期间可以继续查订单 / 库存及添加下一批草稿。仅已明确完成的批次从清单移除，失败或结果不明时保留。

## 实现与边界

手机草稿和待确认的提交意图使用本地持久化，按服务器隔离。提交前冻结批次 UUID，服务按同一 UUID 去重；断网或应用重启后再次确认该批，不创建新单据。报损、报溢分别生成 XLS 并由一个后台工作线程顺序导入，不逐件操作 ERP。

5191 独立保存批次、导入文件、回执和浏览器配置目录；不改 5088 服务、代码、旧草稿或源 Excel。原版模板字段及报损 / 报溢类型选择步骤保留。成功需新出现的导入回执、匹配明细条数及完成标记；首次提交尝试前写入标记，之后异常归为待核对，禁止自动重传。

独立浏览器第一次使用会调用原登录流程；若 ERP 要求人工登录，请在工作台电脑完成。库存数值随后续 ERP 库存导出更新，上传后不直接改手机中的只读库存快照。局域网访问范围保持，公网部署仍未开启。
