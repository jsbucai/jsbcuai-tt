N150 现有 `erp.json` 在 2026-09-29 调用只读接口时，管家婆返回错误码 15（账套授权失败）。同一套参数在 9 月 27 日曾成功，而原电脑 9 月 29 日仍能读取 API，因此优先按“原电脑续期后，N150 保存的 Token 已落后”处理。

请将原电脑当前正在使用、且可成功调用只读 API 的完整授权 JSON 复制到：

```text
\\192.168.100.1\NAS\开发项目\UL随行\N150授权更新-20260929\erp-current.json
```

同目录再放一个 `README.md`，只写：

- 导出时间；
- 账套 ID（可写完整 ID，不要写 Token 值）；
- 导出前成功执行的只读方法名和成功时间；
- `erp-current.json` 的 SHA-256。

不要把 appsecret、signkey、auth_token 或 refresh_token 写入 Markdown、聊天或日志。N150 导入后会将文件保存为权限 600，先只做只读校验，不写物流信息。
