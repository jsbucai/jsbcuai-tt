# 录单工作台手动导入

在现有录单工作台核对编码、数量、价格、摘要和交期，保存后点击“校验并确认”，再点击“下载导入表格”。下载的是已填好的管家婆原格式 `.xls`，不是“导出核对表”的 `.xlsx`。页面同时提供空白原模板下载。

在管家婆进入“系统 → 导入导出 → 业务单据导入”，选择“销售订单”，上传本单表格。导入后核对所有单据、发货信息与未审核状态，再在工作台点击“我已手动导入”。这表示人员报告已完成导入，系统没有执行 ERP 回查或审核。

每个已确认原始订单行对应“客户订单号#原行号”。重复商品行保留，数量单位为支，税率13%，未税单价3位、未税行金额2位；摘要和明细备注共用现有已确认规则，并在末尾保留交期。附加说明留空。仓库为江苏优螺，制单人为罗健树，经手人沿用本单李瑄或刘锋。

表格生成后冻结本次确认稿和文件，反复下载返回原文件；刷新数据不会替换其内容。此时状态为“待人工导入”，API 提交暂时不可点击。尚未上传 ERP 时，可点击“尚未导入，取消”，然后修改草稿或使用原 API 功能。取消后旧下载表格不可再用。已经导入或结果不确定时，应先在 ERP 核对，不能通过取消或新建对话重复提交。

已经有 API 或网页提交事实的对话继续保留原核对表和回执；不生成另一份待导入表格。现有 API 提交、App、微信、采购功能和权限范围保留。N150 浏览器执行仍停用。
