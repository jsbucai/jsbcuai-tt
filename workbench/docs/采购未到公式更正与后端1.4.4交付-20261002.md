# 采购未到公式更正与后端 1.4.4 交付

日期：2026-10-02

## 业务口径

本次恢复并确认原电脑冻结分类基线使用的完整等式：

`可销售库存 = 实物库存 - 销售未完成需求 + 采购未到`

因此：

`采购未到 = 可销售库存 - 实物库存 + 销售未完成需求`

需求必须先按账套、08390仓库、商品、SKU和基本单位汇总一次。活动订单和已出库未记账的影子需求都参与汇总；不得逐张订单重复加入。负数表示数据口径不闭合，继续阻断该库存分配范围，不能按零处理。

`26502066#130*` 的 LS1504 实时数据为实物库存10、可销售库存30、未完成需求20，因此采购未到为 `30-10+20=40`。FIFO 给该单分配10个现货和10个未到，缺口为0；其交期为2026-08-20，按交期规则最终分类为“催货”。

## 实现

- `logistics.py` 和 `business_rules.py` 先汇总同库存身份全部需求，再反推采购未到并执行 FIFO。
- `erp_source.py` 发布的库存 `purchase_pending` 使用同一公式。
- 库存子集刷新从当前已发布订单汇总需求，避免报损报溢草稿上传后的局部刷新恢复旧公式。
- 规则版本升级为 `5-api-*`；Android 接口和 APK 版本不变。
