# 产品图片类型兼容修复 1.4.8

日期：2026-10-02

## 问题与修复

ERP 图片 CDN 对 FB1157 返回的是有效 PNG 文件，但 HTTP `Content-Type` 错标为旧式
`image/pjpeg`。旧版 N150 要求响应头与文件内容类型完全相同，因此内容接口返回 502
“ERP 商品图片格式无效”，Android 无法取得图片字节。

后端 1.4.8 保留固定图片域名、HTTPS、文件大小和文件头校验，并增加受限兼容矩阵：

- 实际 PNG 允许空类型、`application/octet-stream`、`image/png` 和已实证的 `image/pjpeg`。
- 实际 JPEG 允许空类型、`application/octet-stream`、`image/jpeg` 和 `image/pjpeg`。
- 实际 WebP 只允许空类型、`application/octet-stream` 和 `image/webp`。
- HTML、未知文件头及其他跨格式错配继续拒绝。
- 缓存和客户端响应始终使用文件实际类型；图片响应增加 `X-Content-Type-Options: nosniff`。

ERP 原图没有修改，Android 代码和 APK 没有变化。
