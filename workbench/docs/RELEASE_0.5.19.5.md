# 0.5.19.5：采购缺口优先与库存包装任务退出

2026-10-11 已发布并在线核验；后端补丁，Android 继续使用 0.4.13-dev。

## 业务规则

- 已分配实物与采购在途不足以满足需求时，归需采购。部分来货滞留、交期临近或逾期都不能覆盖采购缺口。
- 已采购齐但尚未到齐时，保留待到货／催货；实物齐备并属于来货包装时归来货件。既有超过 7 个自然日的到货滞留提醒保留，整单到齐后才使用异常分类。
- 同单多行中，需采购、催货、待到货优先于另一行的到货滞留。保留每行实际、在途、缺口及原到货证据；不改变 FIFO、订单明细身份或库存单位。
- API 完整分类与兼容分类采用相同优先级，规则版本升为 `5-api-5`。
- 有可靠当前来源证明已转为需采购／催货／待到货／来货件的库存包装任务，若尚未开始且独立打印状态为未打印，则退出库存包装当前列表。历史和原负责人保留；已开始、包装、打印或状态不确定的工作仍需核对。
