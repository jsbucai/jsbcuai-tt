# N150/API 迁移开发版

此目录是独立开发副本。2026-10-02 的 0.3.3 增加订单一级物流分类栏，保留 LS／LD／LM／DQ／QT 五类库存细分，并将订货日期和交期筛选改为日历点选。真实 API 查询缓存和一键后台同步继续由 N150 承载。报损报溢仍由原电脑局域网上传。

当前地址：`https://ul.yingyinghome.com:8443`。最新后端变更见 [1.4.8 产品图片类型兼容修复](docs/产品图片类型兼容修复1.4.8-20261002.md)；订单与物流验收见 [0.3.3 物流全量差异与订单筛选交付](docs/物流全量更新与订单筛选0.3.3交付-20261002.md)；之前的安全试写见 [ERP 物流试写验收与正式启用](docs/ERP物流试写验收与正式启用-20261002.md)。完整功能基线见 [0.3.0 库存台账、产品主图与订单筛选报告](docs/库存台账产品主图与订单筛选0.3.0交付-20260930.md)。

当前数据来自完整分页的奇门未发货清单、WMS 摘要、商品/仓库/库存及 2026-08-07 以来的库存变动单据。销售数量按已经确认的剩余未发数量处理；同一账套、08390仓库、商品、SKU和基本单位下，先用 `saleqty - qty + 全部销售未完成需求` 得到净调整，其中已出库未记账的影子需求也参与汇总。正数作为采购／改制未到，负数作为推算其他占用扣减有效实物库存。物流日期读取摘要末尾的 `#交期=YYYY-MM-DD`，缺少该标记的订单可以查询和打印，但分类保持阻断且不会写回物流。

N150 已部署服务 1.4.8／镜像 0.4.8，数据库仍为 SQLite v4。图片代理可以兼容 ERP 将有效 PNG 错标为 `image/pjpeg` 的情况，并继续按文件实际类型向 App 返回。业务更新只由 App 手动触发；自动同步和完整核对 timers 保持禁用，自动一致性备份继续启用。物流更新在一次手动任务中处理所有合格差异，已成功缓存且目标未变的订单不重复写入；超时仍进入待核对，不自动重发。

实施状态、测试、缺失依据与部署步骤见 [迁移记录](docs/N150_API_MIGRATION.md)。
现有 README 和历史交接文件描述旧版行为；迁移状态以此记录为准。
