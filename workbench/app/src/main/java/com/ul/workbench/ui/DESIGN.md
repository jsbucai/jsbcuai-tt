# UL 原生作业界面

这是面向日常包装的原生手机工具。按最新用户要求，设计采用红、白、黑：中性极浅灰背景、纯白内容、黑色文字和品牌红操作。参考喜利得与伍尔特的单色调识别感，不使用厚重工业面板、渐变装饰或 WebView。

## 视觉约定

- 背景 `#F5F5F6`，内容 `#FFFFFF`，品牌红 `#D71920`，主字 `#1C1D20`，辅助字 `#61646B`。红色用于关键操作、选中和需求数量；成功反馈使用黑字与勾选，错误使用红字与明确说明。不使用奶油色或墨绿色。
- 面板 18dp、输入与按钮 14dp、导航指示器胶囊。面板依靠轻描边和间距区分，避免层层阴影。
- 标题 26sp，商品或客户主信息 16sp，辅助信息 12–14sp。中文沿用系统字体，数字启用等宽数字特性。
- 常用操作至少 48dp。所有文字随系统字号放大；长商品名、设备名与地址可换行，数量与状态不依赖颜色表达。
- 状态变化使用约 160ms 的淡入、尺寸变化；不循环播放装饰动效。

## 信息与操作

三个底部入口：订单、库存、设备。订单和库存中，扫码提示为非编辑区域，默认不召唤软键盘。手动输入明确展开，键盘提交后关闭；拆箱输入使用同窗口的独立原生编辑页面，顶部保留查询上下文与取消操作，避免跨弹窗的焦点与键盘生命周期冲突。

订单顶部保留查询范围。全部 / 库存件与物流公司入口保持同行 48dp；点击“五类”或公司简称后打开原生单选框，列出 LS、LD、LM、DQ、QT。筛选弹窗与手动输入一样暂停接码，收起后恢复。

首次打开保留完整扫码引导。查询后标题压缩为 48dp，扫码状态行约 56dp，间距缩为 10dp；需求、可售、库存紧接扫码行，商品说明置于数量之后。320dp 常规字号下三项数量无需滚动可见，390dp 下首个订单标题可见。未取得的数据显示“—”，与真实 0 区分；系统大字号允许列表滚动，不截断关键数量。

订单内容按客户、订单号、商品、数量排序。选择状态使用勾选和浅色背景同时表达。批量打印与拆箱操作放在底部导航上方，拇指可达；列表预留完整操作条空间，不覆盖最后一行。

库存沿用同一操作语言，以货位与可售数量为重点。设备页首先说明当前连接，再显示可连接设备；服务器地址和测试操作有清晰标签及结果反馈。

加载、尚未查询、查询无结果、失败、打印中、已发送、结果不确定分别表达。成功提示返回作业页并可继续扫码；失败和不确定状态不使用成功配色，也不自动补打。

## 代码边界

- `ui/theme/`：颜色、间距、字号、圆角和 Material 3 主题。
- `ui/components/`：图标、按钮、扫码提示、数量、空态与状态反馈。
- `ui/screens/`：页面组合与局部编辑交互。
- UI 接收状态和回调，不持有网络、蓝牙或打印传输实现。业务默认空态使用真实状态，不内置示例订单充当数据。

原生布局验收覆盖 320dp、常见 360–430dp 和大字号。自动化只能核对 Compose 状态与布局；扫码枪、输入法及实际出纸必须另做真机验收。
